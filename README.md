# Real Estate Platform

## Первоначальный план

Платформа для рынка новостроек города Сочи, объединяющая застройщиков, агентов и клиентов. Проект включает интерактивную карту с детальной информацией об объектах, поэтажными планами и чат-ботом для помощи пользователям.

### Планируемый функционал
- Интерактивная карта с информацией о локациях и объектах недвижимости, фильтрацией и поиском
- Личные кабинеты для застройщиков, агентов и клиентов (?)
- Детальная информация об объектах: инфраструктура, поэтажные планы, что еще?
- AI-помощник для консультаций

### На долгосрочную перспективу
- 3D-туры
- Онлайн-бронирование
- Интеграция с банками
- Мобильное приложение 
- Расширение на другие города (и страны 😎)
